# StarSpeed Browser

A fast, secure, and feature-rich browser based on Chromium, designed for Chinese users.

## Features

- Built-in support for extensions
- Fast browsing experience
- Secure and private
- Customizable UI
- Optimized for Chinese users

## Build Instructions

1. Install depot_tools
2. Run `gclient sync`
3. Run `gn gen out/Default`
4. Run `ninja -C out/Default chrome`
